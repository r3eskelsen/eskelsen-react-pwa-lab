# Manual GitHub upload

1. Keep the final release ZIP, checksum and report in the project's `final` directory.
2. Extract `eskelsen-react-pwa-lab-v0.1.0-GITHUB-READY.zip` into a separate folder. Open the extracted `eskelsen-react-pwa-lab` folder.
3. Create the GitHub repository `eskelsen-react-pwa-lab` manually. Upload the extracted repository contents, including README, LICENSE, docs, evidence, source, tests, scripts, public assets, package files and tsconfig. Use a Git client if the web uploader skips dotfiles or rejects file counts; the ZIP itself is not a substitute for browsing source in the repository.
4. Do not upload node_modules, dist, final, private evidence, browser profiles or personal screenshots. `.env.example` is intentionally empty of secrets.
5. Do not choose a conflicting GitHub-generated open-source license. The current LICENSE reserves rights.
6. Clone into a clean directory and run the README commands. Save the actual repository URL in your release notes after publication.

No repository has been created or published by this delivery. This source is configured for root-origin hosting; GitHub Pages repository subpaths are not supported without changes.
